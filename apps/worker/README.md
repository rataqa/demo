# api

Demo worker working with RabbitMQ.

## requirements

* Node.js v22.x or higher
* RabbitMQ (or an AMQP broker)

## install

```sh
npm i
```

## configure

Copy `_sample.env` as `.env` and edit.

## run

```sh
npm run build
# JS code
npm run start
# TS code
npm run start:ts
```
